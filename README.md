# Gomatch

网络五子棋联机对战平台。基于 **JavaFX + Socket 多线程服务端 + JDBC** 架构，支持玩家实时对弈、房间管理、聊天、观战、战绩排行等功能。

## 快速启动

```powershell
# 启动客户端
.\run-client.ps1
```
