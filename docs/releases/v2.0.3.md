# v2.0.3 版本说明

## 本次更新

### 修复

- **Redis Pub/Sub 连接泄漏**：订阅连接存入连接池，新增 `unsubscribe()` 关闭连接
- **重连 NPE**：`getSessionByUserId` 捕获为局部变量，防 session 过期后空指针
- **异常静默吞**：多处 `catch (Exception ignored) {}` 改为 stderr 输出，便于排查
- **邮件 TTL 文案**：从硬编码"60 秒"改为动态读取实际 TTL（120 秒）
- **Room.leave 空防御**：入口增加 null handler 判断
- **ServerMain 重复初始化**：移除冗余的 `StorageManager.initialize()` 调用

### 文档

- **DB_DESIGN.md**：schema 全面对齐 `init.sql`（~50 处修复）
- **SERVER.md**：密码策略、表名、RedisManager 方法表更新
- **PRD.md**：注册流程补充多标识登录；版本追加 v5.1
- **COMMON.md**：补充 `TIME_SYNC`/`TIMER_PAUSE` 协议常量
- **DEV_GUIDELINE.md / DEPLOY_GUIDE.md / README.md**：版本号与密码描述同步
- 删除重复文件 `CLIENT_STYLE_GUIDE.md`
