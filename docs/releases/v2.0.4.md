# v2.0.4 版本说明

## 本次更新

### 修复

- **移除 ProGuard 混淆**：混淆导致 FXML 引用的控制器与自定义组件类名（如 `AsciiTextCanvas`）与运行时类名不匹配，客户端打包后启动崩溃。已移除 `proguard-maven-plugin` 及 `proguard.conf`，改为纯 shade 打包。

### 文档

- **DB_DESIGN.md**：同步数据库设计文档至 `init.sql` 和 Java 实体代码

## 安装与升级

1. 客户端下载最新 MSI 安装包覆盖安装即可

## 已知问题

- 部分窗口快速拉伸场景下棋盘重绘可能有短暂残影
- 暗色主题下部分第三方弹窗控件可能未完全适配
