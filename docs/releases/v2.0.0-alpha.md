# v2.0.0-alpha 版本说明

## 本次更新

### 新增

- **忘记密码邮件验证**：实现真实邮箱验证码发送功能，支持通过邮箱重置密码
- **安全加密体系**：服务端密码升级为 BCrypt 哈希存储，客户端本地凭据使用 AES-GCM 加密，兼容旧明文密码平滑迁移
- **凭据管理重构**：统一运行时凭据为 `.env` 与环境变量加载，MySQL/Redis/OSS 凭据不再提交到资源配置
- **双方准备机制**：房间内双方点击准备后才开始游戏，替代原有的直接开始逻辑
- **回合计时同步**：新增 TIME_SYNC 协议，断线重连后回合同步当前倒计时，观战方倒计时同步
- **悔棋/求和次数限制**：对局中悔棋与求和各有次数上限，防止滥用
- **国际化和主题**：实现中英文双语国际化支持，完善暗色主题全界面覆盖与可读性修复
- **客户端 MSI 发布流程**：新增 CI 自动打包与 GitHub Release 工作流

### 修复

- **登录与认证**：封禁用户提示已封禁而非误导性报错、手机号登录修复、非数字标识符登录不再匹配 AI 占位记录
- **棋盘游戏**：悔棋/求和请求后暂停/恢复回合计时、再来一局后重置次数计数、刚开局空棋盘禁止悔棋
- **UI 渲染**：D3D 渲染管线 NPE 修复、悔棋/求和弹窗透明替换为无标题栏模式、头像裁剪框拖动优化
- **网络与房间**：断线重连后倒计时同步、双方同时断线时立即销毁房间、观战列表为空修复
- **好友系统**：在线状态误判离线修复、好友请求列表渲染失败修复、暗色主题可读性修复
- **排行榜**：AI 用户排除、好友头像不显示修复、头像颜色前后端键名统一
- **数据库**：`init.sql` 约束与种子数据不匹配修复、手机号允许为 NULL 支持选填注册
- **内存与性能**：后台静音内存泄漏修复、全屏切换闪烁修复、凭证存储旧明文密码残留清理

### 优化

- **AI 难度分化**：简单/中等/困难三种难度实现差异化策略，困难模式引入 alpha-beta 剪枝 MiniMax
- **头像系统**：头像字段统一重命名为 `avatarUrl`，支持 OSS 可选配置与本地回退，去除天蓝色默认背景
- **代码质量**：消除 OSS 重复代码、修复 TOCTOU 竞态条件、统一 JSON 协议收发、移除未接入的业务代码
- **构建流程**：取消 Maven forked javac 编译、客户端启动不再强制清理构建目录

### UI 视觉升级

- React Bits PixelCard 粒子像素化悬浮效果 + TiltedCard 3D 倾斜 + Lanyard 吊绳摇摆动力学
- 全局磨砂玻璃极简风格统一，自定义标题栏与 Windows Aero Snap 贴边支持
- 棋盘侧边栏折叠/拖拽拉伸、侧栏按钮防裁剪垂直堆叠、棋盘自适应缩放
- 排行榜拆分为全服/好友双榜、好友大厅侧栏化重构、设置页六面板布局

### 安全加固

- IP 速率限制、超大包保护、恶意重连校验
- 单点登录竞态条件修复、封禁用户登录阻断
- 连接成功提示隐藏服务器真实 IP 和端口

## 安装与升级

1. 将 `.env.example` 复制为 `.env`，填写 MySQL、Redis 与可选 OSS 凭据
2. 执行 `sql/init.sql` 初始化数据库（表结构有变更）
3. 运行 Release 附带的 MSI；安装程序会覆盖旧版本

## 已知问题

- 部分窗口快速拉伸场景下棋盘重绘可能有短暂残影
- 暗色主题下部分第三方弹窗控件可能未完全适配

## 注意事项

- 此为 **alpha 预发布版本**，可能存在未发现的缺陷，建议在测试环境先行验证
- 旧版本客户端凭据文件（`password` 属性）会在首次登录后自动迁移为 AES-GCM 加密格式
