# v2.0.2 版本说明

## 本次更新

### 修复

- **注册手机号必填**：注册页面手机号从选填改为必填，与服务端校验对齐
- **好友请求头像**：补齐 FriendDAO → ClientHandler → FriendsController 4 层头像数据链路，好友申请页面请求方头像从纯文字改为异步图片加载
- **悔棋/求和弹窗透明**：次数上限提示弹窗添加 `glass-card` CSS 类，修复 TRANSPARENT 舞台下背景不可见的问题
- **D3D 管线 NPE**：jpackage MSI 打包添加 `--java-options "-Dprism.dirtyopts=false"`，规避 D3D 脏区域优化导致的 GPU 资源空指针崩溃
- **CI deploy-server**：添加 `environment: 1` 声明以接入环境级 SSH secrets，新增凭据预检，缺少 secrets 时优雅跳过部署步骤

## 安装与升级

1. 客户端下载最新 MSI 安装包覆盖安装即可
