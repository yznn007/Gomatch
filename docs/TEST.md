# Gomatch 测试用例表

对应学校模板 `docs/school_materials/测试用例表.pdf`。四类必测：冒烟（主流程走通）/ 边界（异常输入）/ 越权（角色隔离）/ 并发（多客户端同时操作）。

## 一、冒烟测试（主流程）

| 编号 | 场景 | 步骤 | 预期 | 实际 | 通过? |
|------|------|------|------|------|-------|
| S01 | 注册登录 | 注册新用户→登录 | 拿到 userId/role，进入游戏大厅，建立 Socket 连接 | | |
| S02 | 创建房间 | 大厅→普通对战→创建房间 | 房间创建成功，进入房间等待界面 | | |
| S03 | 加入房间 | 房间列表选择一个房间加入 | 进入房间等待界面，显示双方信息 | | |
| S04 | 快速匹配 | 点击快速匹配按钮 | 匹配到对手后自动进入房间等待→开始对局 | | |
| S05 | 排位匹配 | 排位大厅→开始排位匹配 | 按 ELO 积分匹配对手，进入对局 | | |
| S06 | 落子同步 | 对局中点击棋盘落子 | 双方棋盘同步显示落子，轮次切换 | | |
| S07 | 五连判胜 | 连续落子形成五连 | 服务端判定胜负，弹出对局结束弹窗 | | |
| S08 | 认输 | 对局中点击认输按钮 | 对方获胜，弹出对局结束弹窗 | | |
| S09 | 悔棋 | 点击悔棋→对方同意 | 棋盘回退一步，轮次恢复 | | |
| S10 | 求和 | 点击求和→对方同意 | 对局结束，双方平局 | | |
| S11 | 房间聊天 | 在聊天框输入消息发送 | 双方和观战者都能看到消息 | | |
| S12 | 观战 | 进入对局中的房间观战 | 同步显示棋盘状态和聊天，不能落子 | | |
| S13 | 战绩查询 | 个人中心→对战记录 | 显示历史对局列表，可回放有棋谱的记录 | | |
| S14 | 排行榜 | 大厅→排行榜抽屉 | 按积分排序显示排名、用户名、胜率 | | |
| S15 | 人机对战 | AI 大厅→选择难度→开始 | 进入对局，AI 能落子，胜负判定正常 | | |
| S16 | 好友系统 | 添加好友→对方接受 | 好友列表更新，可查看好友请求 | | |
| S17 | 设置页面 | 设置→切换主题/语言/音量 | 设置即时生效并持久化 | | |
| S18 | 浏览模式 | 登录页→浏览模式 | 无服务器时可进入主要界面，假数据填充 | | |
| S19 | 再来一局 | 对局结束→再来一局 | 双方同意后重置棋盘开始新对局 | | |
| S20 | 断线重连 | 对局中断线→重连 | 恢复会话和房间状态，棋盘回放 | | |
| S21 | 忘记密码 | 登录页→忘记密码→邮箱→验证码→重置 | 验证码 5 分钟有效，重置后可用新密码登录 | | |
| S22 | AI 难度选择 | AI 大厅→选简单/中等/困难→开始 | 三档难度 AI 落子策略不同 | | |
| S23 | 管理员封禁 | 管理控制台→封禁→解禁 | 被封禁用户无法登录，解禁后恢复 | | |
| S24 | 暗夜主题 | 设置→切换暗夜黑磨砂 | 全界面切换为暗色并持久化 | | |
| S25 | 中英文切换 | 设置→切换语言 | 全界面文本切换并持久化 | | |
| S26 | 背景音乐 | 设置→开启大厅音乐→调音量 | 音乐循环播放，音量即时变化 | | |

## 二、边界测试（异常输入）

| 编号 | 场景 | 输入 | 预期 |
|------|------|------|------|
| B01 | 重复用户名注册 | 注册已存在的用户名 | 返回"用户名已存在" |
| B02 | 密码错误登录 | 输入错误密码 | 返回"用户名或密码错误" |
| B03 | 加入满房间 | 加入已满 2 人的房间 | 返回"房间已满" |
| B04 | 密码房间错误 | 输入错误房间密码 | 返回"房间密码错误" |
| B05 | 非己方回合落子 | 对方回合时点击棋盘 | 服务端拒绝，不更新棋盘 |
| B06 | 重复落子 | 在已有棋子的位置落子 | 服务端拒绝，返回错误 |
| B07 | 观战者落子 | 观战模式下点击棋盘 | 客户端禁用落子，不发送请求 |
| B08 | 用户名含特殊字符 | 用户名含 `\|` 或换行 | JSON 编码处理，不破协议 |
| B09 | 聊天消息含特殊字符 | 消息含 JSON 特殊字符 | 正常显示，不崩协议 |
| B10 | 空消息发送 | 发送空聊天消息 | 客户端拦截或服务端忽略 |
| B11 | 不存在的房间 | 加入已解散的房间 | 返回"房间不存在" |
| B12 | 超长消息 | 发送超长聊天内容 | 截断或返回错误 |

## 三、越权测试（角色隔离）

| 编号 | 场景 | 步骤 | 预期 |
|------|------|------|------|
| P01 | 观战者发落子命令 | 构造报文发送 MOVE | 服务端拒绝，返回"观战者不能落子" |
| P02 | 普通玩家发管理命令 | 构造报文发送封禁/踢人 | 服务端按 role 校验拒绝 |
| P03 | 客户端藏入口不等于安全 | 绕过客户端 UI 直接发管理命令 | 服务端仍必须按 role 拦截 |
| P04 | 查看他人对战记录 | 玩家查询他人对战记录 | 只能查自己的记录 |
| P05 | 非房主开始游戏 | 非房主点击开始按钮 | 服务端校验房主身份 |

## 四、并发测试

| 编号 | 场景 | 步骤 | 预期 |
|------|------|------|------|
| C01 | 同一房间两人同时落子 | 2 个客户端同时点击棋盘 | 仅当前回合方落子成功，另一方被拒 |
| C02 | 并发注册同一用户名 | 2 个客户端同时注册相同用户名 | 仅 1 人成功，另一人收到"用户名已存在" |
| C03 | 快速匹配并发 | 多人同时快速匹配 | 匹配队列 FIFO 正确配对，不重复 |
| C04 | 多客户端同时在线 | 多个客户端同时登录 | 在线数正确递增，服务端不崩溃 |
| C05 | 断线同时重连 | 多人同时断线重连 | 会话恢复正确，不串房间 |
